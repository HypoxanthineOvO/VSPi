# VSPi v0.1.0 可用性修复

VSPi v0.1.0 具有一致且可预测的全局键位语法、正确的两行状态信息层级、可完整操作的 Question 与 Settings、诚实隔离的 Demo 能力和真实可用的 Model 切换；用户可在 80x24 终端完成核心工作流后，再恢复公开发布准备。
