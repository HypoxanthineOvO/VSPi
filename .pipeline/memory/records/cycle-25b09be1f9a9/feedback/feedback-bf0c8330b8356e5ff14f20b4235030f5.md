# Delivery feedback

Problem: 命令列表不标示 alias 命中来源，唯一候选没有 Tab 补全，composer、内置命令和插件命令缺少统一匹配高亮；命令行内容全部左对齐且缺少按宽度分配的列间距；面板下方没有常用按键灰字提示。
Reproduce: 输入 /ex 并观察 /quit 的 alias 匹配显示。 在唯一候选时按 Tab。 输入内置与插件命令前缀并检查 composer 与结果高亮。 在 80 与 120 列比较命令行的说明和来源列位。 打开 Command、Model、Update、Sessions 与 Question 面板并检查底部键位提示。
Expected: Alias 命中先显示别名并指向 canonical command，唯一候选可按 Tab 补全当前 canonical 或 alias token；slash token 与所有匹配片段有非颜色单一的高亮；命令身份、说明和来源按可用宽度均匀分列；面板下方显示上下文灰字快捷键提示。
Actual: 当前只显示 canonical command 行，无法判断由哪个 alias 命中；Tab 不补全；命令和插件匹配没有统一高亮；结果行左侧堆叠；面板无常用键提示。
Context: Revision 1 已完成空状态、持久 splash、状态栏、模型双栏和 Update fixture，但在最终验收时补充了 command discovery 与 keyboard discoverability 要求，现纳入 Revision 2。
