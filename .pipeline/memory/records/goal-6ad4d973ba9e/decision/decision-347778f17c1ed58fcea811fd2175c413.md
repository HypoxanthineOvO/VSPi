# VSPi 持久 Goal Runner与终端瀑布修订

VSPi 通过 `/goal` 提供项目持久、可恢复且有安全边界的长期任务执行：模型维护 Working Plan 与 Progress Markers，普通阶段总结不会终止未完成 Goal，只有真实完成、阻塞、暂停、取消或预算边界能够停止自动续跑。 同时修正启动与 Transcript 的物理终端布局，使 Splash、内容、Composer 和状态行按真实瀑布连续增长与滚动。
