# VSPi 持久 Goal Runner、终端瀑布与 Mock-first 恢复修订

VSPi 通过 `/goal` 提供项目持久、可恢复且有安全边界的长期任务执行：模型维护 Working Plan 与 Progress Markers，普通阶段总结不会终止未完成 Goal，只有真实完成、阻塞、暂停、取消或预算边界能够停止自动续跑。 同时修正启动与 Transcript 的物理终端布局，使 Splash、内容、Composer 和状态行按真实瀑布连续增长与滚动。 Question 交互区与主 Composer 之间保留稳定视觉间隔，避免等待态的双输入区域拥挤。 新增可运行的真实终端 Mock 作为时序、坐标与性能 oracle；流式发送保持增量，Resume 通过原子 surface epoch 恢复，不再重播启动内容或打乱动画与框。
