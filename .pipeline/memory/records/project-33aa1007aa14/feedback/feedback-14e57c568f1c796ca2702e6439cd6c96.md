# Fullscreen Session history authority

Fullscreen TUI 使用 alt-screen 与 ScrollView 管理 transcript 和 viewport；会话恢复不得再执行 regular TUI 的 append-only surface epoch 或 committed-history rebase，否则长历史会被截断或刷新错乱。regular TUI 可以保留其专用 scrollback 机制。
