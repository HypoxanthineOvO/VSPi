# Windows Session lease uses named pipes

VSPi 0.6.0 crashed on Windows with `listen EACCES` when binding the Session lease socket at a filesystem path such as `C:\Users\<user>\.pi\agent\session-leases\...sock`. On Windows, `net.listen`/`net.connect` must use a named pipe such as `\\.\pipe\vspi-session-...`; filesystem socket semantics (`chmod`, `unlink`, directory containment) do not apply. Fixed in 0.6.1.
