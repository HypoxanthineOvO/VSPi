# 默认 TUI 模式采用 regular

VSPi 项目默认 `tuiMode` 使用 `regular`（非 FullScreen），以终端原生 scrollback 获得更流畅的长历史滚动体验。fullscreen 保留为可选模式，可通过 Settings、`/tui` 或 `VSPi_TUI_MODE=fullscreen` 显式启用。
