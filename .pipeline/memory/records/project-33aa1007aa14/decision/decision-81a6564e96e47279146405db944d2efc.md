# Pi Editor 0.84.2 性能补丁与运行时冻结加固

C13 采用版本守卫的 Pi Editor 性能补丁和 PTY/runtime 冻结加固，作为 0.6.3 之上的修订：

- `postinstall` 通过 `scripts/patch-pi-editor-performance.mjs` 对 `@earendil-works/pi-tui` 0.84.2 的两份安装（direct 与 pi-coding-agent nested）应用 grapheme/折行缓存与水平移动优化；源码结构或版本不匹配时 fail closed，upstream 修复后可整体删除。
- `shutdownInteractiveSession` 先停止 TUI 再 dispose，并为 dispose 提供默认 10s 超时，避免 backend abort 不收敛时残留 raw mode 或阻塞退出。
- 交互式 TTY 会话启用 launcher parent-death watchdog（`VSPi_NO_PARENT_WATCHDOG=1` 关闭）；launcher 消失时退出并恢复终端，防止 PTY 前台 shell 被孤儿进程卡住。
- 单个 thinking 块渲染端截断到 200,000 字符（完整消息数据保留在消息对象中），避免超长 streaming 块被完整送入 Markdown/layout 造成无界重绘与写入。
- M3 视觉基线恢复 0.6.2 Unicode 视觉语言（圆角 Composer、block-art splash 与既有语义字形），不支持 Unicode 的终端走 capability ASCII 回退；0.6.3 已验证的功能修复（render cache、Provider 兼容等）保留。
