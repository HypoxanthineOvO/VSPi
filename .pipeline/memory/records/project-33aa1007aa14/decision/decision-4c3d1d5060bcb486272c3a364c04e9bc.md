# Remove SSH Attachment Bridge

Remove the SSH Attachment Bridge backend and all product surfaces: automatic startup, URL notices, browser upload page, Settings toggle, CLI command, help text, and documentation. Preserve local clipboard/file attachments, SSH command approval and classification, and SSH-aware Provider authentication. Remote SSH image paste through the Bridge is intentionally no longer supported.
