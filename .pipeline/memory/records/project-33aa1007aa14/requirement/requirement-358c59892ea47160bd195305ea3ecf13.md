# Interactive panel information density

Audit authorization management and configuration panels in the next VSPi version. They currently feel thin and crowded even on wide terminals because too many labels, statuses, hints, and details are simultaneously visible. Retain wireframes but reduce default information exposure, add deliberate internal padding and whitespace, keep primary choices prominent, and move secondary explanations to selection, expansion, or deeper views. Apply one coherent density system across Question, approval, Settings, Policy, Tools, Provider, and related interactive panels.
