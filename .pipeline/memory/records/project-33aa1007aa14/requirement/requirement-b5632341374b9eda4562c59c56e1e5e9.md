# Interactive surface hierarchy and component layout

Preserve the approved spatial classes, user-message blue marker, original Braille Working frames, full-width command rows, visible Question descriptions, and prominent approval command surface. Render approval actions as an ordered list so users can scan and select by number. Preserve the existing session branch tree drawing such as `└─`; it represents a session fork derived from a parent session, not a Subagent. Selected session details may name the parent to make that meaning explicit. Render Plan through the existing complete VSPi Plan snapshot and nested renderer, including title, revision, goal, background, challenges, nested items, focus, and next action; do not replace it with a simplified tree.
