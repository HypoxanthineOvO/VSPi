# Interactive surface hierarchy and component layout

Preserve the approved spatial classes and current VSPi visual identity. Keep the user-message background and blue leading marker. Keep Working at the approved position between the message waterfall and bottom interaction area, using the original VSPi Braille flowing frames rather than a moon or replacement indicator. Command completion uses the full available width and displays each command description in a stable column on the same row. Approval makes the exact command immediately prominent in a centered or substantially indented command surface, with deliberate vertical separation before action choices. Sessions label forked conversations explicitly as `分支` rather than using an ambiguous tree arrow that may be mistaken for a Subagent, and selected details show parent session and recent progress. Preserve the original VSPi nested Plan renderer and fold behavior rather than flattening or restyling it. Validate these layouts in an 80x24 native TTY.
