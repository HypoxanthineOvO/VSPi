# Skill and MCP management

For VSPi 0.3, provide a clear terminal-native management surface that inventories installed Skills and MCP interfaces with their source and status. The Skill surface must include an add entry, accept a pasted URL, and support natural-language search and installation through the Agent. Important UI changes must be mocked in the terminal before implementation.
