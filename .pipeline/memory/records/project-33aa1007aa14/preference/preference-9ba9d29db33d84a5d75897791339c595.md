# Prefer upstream TUI component ownership

Prefer Pi official drawing, input, cursor, scrolling, and model runtime components when they satisfy the VSPi interaction contract. Keep VSPi wrappers limited to product-specific semantics and presentation that upstream does not provide. When an upstream algorithm is the source of a performance bug, fix or temporarily patch that narrow algorithm instead of replacing the component or globally substituting UI glyphs.
