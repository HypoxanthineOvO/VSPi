# Preserve the approved Unicode visual language

Terminal width compatibility fixes must preserve the approved VSPi Unicode component design and startup branding. Do not replace the rounded composer frame, block-art splash, animation, or established semantic glyphs with blanket ASCII substitutions. Handle incompatible terminals through measured width logic and the existing capability-specific fallback, and validate the Unicode and ASCII capability paths separately.
