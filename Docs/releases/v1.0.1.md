# VSPi 1.0.1

VSPi 1.0.1 修复长对话中的渲染性能问题，并把用户验收更流畅的 regular TUI 设为默认模式。

## 主要变化

- **默认使用 regular 模式**：历史滚动交给终端原生 scrollback；fullscreen 仍可通过 Settings、`/tui` 或 `VSPI_TUI_MODE=fullscreen` 启用。
- **减少无效写入**：抑制只重复光标尾部的空帧，降低无效 terminal write；fullscreen 滚动期间使用较低帧率，降低大量历史内容滚动时的输出带宽。
- **保留渲染质量**：沿用 upstream assistant renderer 的缓存与 streaming 路径，同时恢复 VSPi 的 Markdown 后处理——分层无序列表、任务列表、代码块与表格样式。
- **可观测性**：增加帧耗时 instrumentation 与长文本 fixture，便于继续诊断超长 streaming 消息。

## 安装

```bash
curl -fL 'https://github.com/HypoxanthineOvO/VSPi/releases/latest/download/vspi-latest.tgz' -o /tmp/vspi-latest.tgz && npm install -g /tmp/vspi-latest.tgz
```

需要 Node.js 22.19.0 或更高版本。
