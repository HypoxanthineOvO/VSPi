# VSPi 1.4.4

VSPi 1.4.4 沿用 1.4.3 的 VSPLab Kimi K3 Provider 修复，并修正 GitHub Release runner 的质量门禁配置。

## Release CI 修复

- GitHub runner 显式安装 `ripgrep` 与 `bubblewrap`，避免工具和安全测试因运行依赖缺失失败。
- GitHub Release 在发布前执行 TypeScript/Biome 检查，以及 Provider catalog、K3 payload、Pi backend、Session backend 和 release publisher 定向测试。
- package 安装验证从 Vitest 内部超时测试移为独立 workflow step；真实安装 release tarball 并核对 `vspi --version`。
- GitLab 专用 CI 继续执行完整 `npm test`，保留 PTY、多进程 handoff、sandbox 和 package install 的全量门禁。

## Kimi K3 修复

- 包含 1.4.3 的全部 K3 修复：VSPLab Kimi instruction 使用 `system` role，不再触发 `400 role 'developer' is not allowed`。
- 本机遗留 `vsplab-open` 已清理，统一使用 `vsplab/k3` 与 `https://api.vsplab.cn/v1`。

## 安装

```text
vspi update
```

或：

```powershell
npm install --global "https://gitlab.vsplab.cn/heyx/vspi/-/releases/permalink/latest/downloads/vspi-latest.tgz"
vspi --version
```

Pinned package: `https://gitlab.vsplab.cn/heyx/vspi/-/releases/v1.4.4/downloads/vspi-1.4.4.tgz`
