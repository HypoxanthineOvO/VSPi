# VSPi 1.3.3

VSPi 1.3.3 修复 regular TUI 临时切出前台再恢复时，界面回到顶部或发生全量重绘的问题。

## Regular TUI 视口恢复

- regular TUI 临时交出前台时保留当前 main screen 与增量渲染状态。
- 回到前台后继续增量渲染，不再重置 render state 或执行带 Home 的全量清屏，原生 scrollback 与当前视口保持不变。
- terminal focus-in / focus-out report 作为终端元数据消费，不再进入 Composer 或触发无意义的 immediate render。
- fullscreen 模式继续使用自身的 alternate-screen 重绘流程，行为不变。

## 验证

- 全量 Vitest 通过（136 个文件、1029 个用例）。
- 覆盖 regular scrollback、真实 PTY、fullscreen、Session handoff 与 continuity 场景。
- TypeScript、Biome、构建和发布 tarball 安装验证通过。

## 安装

已有可工作的 VSPi 可运行：

```text
vspi update
```

或手动安装：

```powershell
npm install --global "https://gitlab.vsplab.cn/heyx/vspi/-/releases/permalink/latest/downloads/vspi-latest.tgz"
vspi --version
```
