# VSPi 1.1.4

VSPi 1.1.4 修复 Resume 会话面板的渲染错乱，并改进状态栏与 Transcript 的视觉层次。

## Sessions / Resume 修复

- 修复多行首条消息作为会话标题时的渲染错乱：标题中的换行符被按零宽保留，一个面板行会占据多个物理行，按 `↑↓` 滚动后出现内容错位、状态栏被会话文本覆盖。会话标题现在在后端源头净化（取首条非空行、压平空白、限长 120），UI 渲染层再加一道单行防御。
- 状态栏通知（Notice）同样压平多行文本，不再被通知内容撑破单行布局。
- 会话行新增运行状态标识：`● 使用中` 表示其他 VSPi 进程持有该会话租约、`当前` 表示本进程正在使用的会话，其余保持相对时间。

## 状态栏修复

- 120 列及以上布局中，Token 槽位从 30 加宽到 34：`Token ↑999k ↓999k Hit Rate: 100%` 的命中率尾数不再被 Cost 锚点截断成省略号。

## Transcript 阅读性

- 思考块内的 Markdown 结构元素（标题、链接、列表符、行内代码、代码块、语法高亮）统一退化为灰调，不再出现正文灰而标题亮蓝的割裂感；代码块不再铺亮色背景，标题保留粗体层级信号。
- Commentary（工具间隙里模型的直接文字输出）恢复正常文本与 Markdown 主题色，仅首行保留弱化 `·` 标记与正式输出（`✦` + 分隔线）区分，不再整块置灰。
- 工具调用保持原有树形灰调展示。

## 验证

- 全量 Vitest 通过（130 个文件、976 个用例），含真实 PTY、Session continuity、package install 与 release surface。
- `npm run check` 通过。
- `npm pack` + `verify-package`、空目录全新安装与 `vspi --version` 验证通过。

## 安装

已有可工作的 VSPi 可运行：

```text
vspi update
```

或手动安装：

```powershell
npm install --global "https://gitlab.vsplab.cn/heyx/vspi/-/releases/permalink/latest/downloads/vspi-latest.tgz"
vspi --version
```
