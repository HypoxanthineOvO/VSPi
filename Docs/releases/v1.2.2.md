# VSPi 1.2.2

VSPi 1.2.2 升级 Pi 0.84.3，增加 Windows PowerShell root 工具，并修正跨 VSPi 会话的 Shell writer lease 边界。

## 平台 Shell

- Linux 与 macOS root session 只提供 Bash。
- Windows root session 只提供 Pi 原生 PowerShell；system prompt 明示 Windows 环境、PowerShell 语法和路径规则。
- Unix Subagent 继续使用 bubblewrap sandboxed Bash；Windows Subagent 暂不提供 shell，避免在没有 Windows sandbox 的情况下暴露 Host PowerShell。
- Windows 不启用依赖 Bash 的 DeepSeek persistent harness。
- PowerShell 保留 VSPi execution policy、审批和审计边界；危险删除、系统与网络命令使用保守风险分类。

## Writer 并发边界

- 同一 `PiAgentManager` / Agent tree 内，文件 mutation 与 opaque shell 继续保守串行。
- 不同 VSPi 会话的 Bash 或 PowerShell 不再获取 workspace-wide writer lease；一个会话中的长 Shell 命令不再阻塞另一个会话的 Shell。
- `edit`、`write` 与 `str_replace_editor` 继续按目标文件获取跨进程 lease；同一文件串行，不同文件可以并行。
- Session、Teammate lane 与 config typed lease 保持不变。

结构化文件工具的 lease 不覆盖 Bash、PowerShell、Git hook、外部编辑器或其他进程。需要强隔离的多会话并行开发仍应使用独立 Git worktree。

## Pi 0.84.3

- `@earendil-works/pi-coding-agent` 与 `@earendil-works/pi-tui` 升级至 0.84.3。
- VSPi Pi Editor performance patch 的精确版本门禁同步升级，并在两个实际 Pi TUI 安装位置验证。

## 验证

- 全量 Vitest 通过（133 个文件、999 个用例），包含真实 PTY、多进程 Session handoff、Agent lease 与 package install。
- `npm run check`、`git diff --check`、真实 tarball install/bin smoke 和生产依赖 audit 通过。
- 平台选择、PowerShell 原生 schema、system prompt、Policy classifier 与 Windows child shell 过滤均有契约测试。

## 安装

已有可工作的 VSPi 可运行：

```text
vspi update
```

或手动安装：

```powershell
npm install --global "https://gitlab.vsplab.cn/heyx/vspi/-/releases/permalink/latest/downloads/vspi-latest.tgz"
vspi --version
```
