# VSPi 1.0.0

VSPi 1.0.0 是首个稳定版本。

## 主要功能

- 真实 Pi 会话、模型与服务商配置、历史会话导入和跨终端接管。
- fullscreen / regular 双界面，以及针对长对话和滚动输出的性能优化。
- 多 Agent 并行协作、持久任务、模型池、失败回退和预算限制。
- Safe、Standard、YOLO、Auto 四档执行策略与交互审批。
- 订阅账号登录、API Key、自定义中转站、Skill、剪贴板图片、Markdown、LaTeX 和 Mermaid。

## 配置命令

`vspi config` 成为服务商与凭据配置的正式入口；`vspi init` 在 v1 中继续作为兼容 alias，并提示迁移。

## 安装

```bash
curl -fL 'https://github.com/HypoxanthineOvO/VSPi/releases/latest/download/vspi-latest.tgz' -o /tmp/vspi-latest.tgz && npm install -g /tmp/vspi-latest.tgz
```

需要 Node.js 22.19.0 或更高版本。
