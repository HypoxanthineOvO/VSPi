# VSPi 1.1.2

VSPi 1.1.2 包含两组修复：Subagent 运行时审计后的止血修复（移除一系列过度限制），以及一次用户报告的模型命令幻觉事故的针对性修复。

## Subagent 运行时修复

- **不再强制使用 Subagent**：删除按关键词要求"显式使用 Subagent"的自然语言门禁，回合末不再以 authority 断言把消息退回给用户；仅保留对持久 Agent 变更的防护。
- **预算不再拦截成果**：run/tree 的 token、cost、时长与 per-parent 的 child/tree 数量不再拒绝或作废 Subagent 成果，只作为遥测警戒线在 UI 标黄；`maxDepth` 默认 3 仍是唯一的 spawn 层级限制；6 个限制字段继续保留在配置中。
- **Teammate 暂时下线**：路由、`task.teammate` 参数与 `/agents model|reset|override` 全部禁用并提示暂不可用；界面不再渲染 teammate 块；`.vspi/agents.json` 数据原样保留。
- **bash 审批分类更准**：丢弃式重定向（`2>/dev/null`）与纯 fd 复制（`2>&1`）不再把只读命令降级为写入审批；真正打开文件写入的重定向仍按原 policy 审批。
- **Subagent 进度可见**：`/agents` 与 Transcript 显示当前工具、轮次、最近活动时间、已运行时长与实际 usage，超警戒线标黄。
- **状态栏微调**：Speed 只显示平均吞吐；Cache Hit Rate（最近请求口径）并入 Token 行——120 列及以上显示，80 列维持原布局以保护 cwd 不被截断。

## 命令幻觉修复

针对一次用户报告的 Windows 会话事故（模型推荐了不存在的命令）：

- 系统提示词注入命令契约：由命令注册表动态生成 VSPi 真实命令清单，并声明上游 pi 文档不适用于 VSPi，杜绝推荐不存在的命令。
- 新增 `/reload`：空闲时平滑重启——自动续接当前会话（复用既有 session lease handoff），用于 `/update` 后生效或修改本体配置后加载；运行中拒绝。
- 安装后移除依赖内捆绑的上游 pi 文档（`docs/`、`examples/`、上游 README）：这些文档描述的是上游 pi CLI 的行为，此前会被模型误当作 VSPi 的事实来源。
- CLI 补常见别名：`vspi -c` / `vspi --continue` 等价 `vspi continue`，`vspi -r` / `vspi --resume` 等价 `vspi resume`。

## 安装

已有可工作的 VSPi 可运行：

```text
vspi update
```

或手动安装：

```powershell
npm install --global "https://gitlab.vsplab.cn/heyx/vspi/-/releases/permalink/latest/downloads/vspi-latest.tgz"
vspi --version
```
