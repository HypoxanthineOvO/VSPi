# VSPi 0.6.2

VSPi 0.6.2 修复全屏运行时在 Windows 验证中发现的三个问题。

## 修复

- **长会话恢复不再花屏**：全屏 Session restore 把 transcript 与视口所有权交还给 alt-screen `ScrollView`，不再套用 regular TUI 的 append-only surface epoch 与已提交历史 rebase。恢复的长对话可以完整滚动浏览，不再需要刷新才能看。
- **切到 Auto Policy 不再被回滚**：Policy 切换在运行时接受后立即生效；可选 Session 恢复元数据保存失败只发出警告，不再把生效中的 Policy 回滚。
- **模型列表排序稳定**：继续按 Provider 分组、新世代在前；同世代内按输入+输出合计价格从高到低，名称与 id 作为稳定兜底。

regular TUI 的 scrollback 专用历史机制不受影响。

## 安装

Windows PowerShell：

```powershell
npm install --global "https://gitlab.vsplab.cn/heyx/vspi/-/releases/permalink/latest/downloads/vspi-latest.tgz"

vspi --version
vspi
```

Linux/macOS：

```bash
npm install -g 'https://gitlab.vsplab.cn/heyx/vspi/-/releases/permalink/latest/downloads/vspi-latest.tgz'

vspi --version
vspi
```

需要 Node.js 22.19.0 或更高版本。
