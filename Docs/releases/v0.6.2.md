## Windows TUI Corrective Fixes

VSPi 0.6.2 fixes three issues found during Windows validation of the fullscreen runtime:

- Fullscreen Session restore now leaves transcript and viewport ownership to the alt-screen `ScrollView`. It no longer applies the regular TUI's append-only surface epoch or committed-history rebase, so long restored conversations remain reachable without refresh corruption.
- Switching execution Policy to `Auto` takes effect once the runtime accepts it. Failure to persist optional Session recovery metadata now produces a warning instead of rolling the active Policy back.
- Models remain grouped by Provider and are ordered newest generation first. Models in the same generation are ordered by combined input and output price from highest to lowest, with stable name and id fallbacks.

The regular TUI keeps its scrollback-specific history mechanism.

### Install

Windows PowerShell:

```powershell
npm install --global "https://gitlab.vsplab.cn/heyx/vspi/-/releases/permalink/latest/downloads/vspi-latest.tgz"

vspi --version
vspi
```

Linux/macOS:

```bash
npm install -g 'https://gitlab.vsplab.cn/heyx/vspi/-/releases/permalink/latest/downloads/vspi-latest.tgz'

vspi --version
vspi
```

Requires Node.js 22.19.0 or newer.
