## Fullscreen Runtime

VSPi 0.6.0 consolidates the accepted work since 0.3.11 into one installable release. The intermediate 0.4 and 0.5 lines were development milestones and were not published as retrospective tags.

### Release milestones

- **0.4 Agent Teams:** in-memory Task Agents, persistent Teammate lanes, typed authority, cross-provider context boundaries, run/tree budgets, cancellation, writer/lane leases, and the `/agents` map and timeline.
- **0.5 Persistent Goals:** workspace-scoped Goal persistence, explicit execution ownership, safe resume semantics, bounded continuation, and terminal/history reliability fixes.
- **0.6 Fullscreen Runtime:** Pi 0.84.1, fullscreen as the default renderer, regular terminal fallback, bounded transcript navigation, and themed Markdown, LaTeX, and Mermaid rendering.

### Compatibility and distribution

- Requires Node.js 22.19.0 or newer.
- Supports installation from the GitLab Release tarball on Windows, Linux, and macOS.
- The release is distributed through GitLab; VSPi is not published to the public npm registry.
- RemoteSession, PiClient, Agent Core v4, independent Agent worktrees, and cross-machine lane handoff remain deferred.
