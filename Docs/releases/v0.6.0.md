# VSPi 0.6.0

VSPi 0.6.0 把 0.3.11 之后验收的全部工作整合为第一个可安装的整合版本。中间的 0.4 与 0.5 是开发里程碑，没有追溯发布 tag。

## 本版包含的三个里程碑

- **Agent Teams（0.4）**：内存态 Task Agent、持久 Teammate 泳道、类型化 authority、跨 Provider 上下文隔离、run/tree 预算、取消机制、writer/lane 租约，以及 `/agents` 总览与时间线。
- **持久 Goal（0.5）**：workspace 级 Goal 持久化、显式执行所有权、安全的 resume 语义、有界续跑，以及一批终端与历史可靠性修复。
- **全屏运行时（0.6）**：升级到 Pi 0.84.1；fullscreen 成为默认渲染器并保留 regular 终端回退；有界 Transcript 导航；主题化 Markdown、LaTeX 与 Mermaid 渲染。

## 兼容与分发

- 需要 Node.js 22.19.0 或更高版本。
- 支持从 GitLab Release tarball 在 Windows、Linux 与 macOS 上安装。
- 仅通过 GitLab 分发；VSPi 不发布到公共 npm registry。
- RemoteSession、PiClient、Agent Core v4、独立 Agent worktree 与跨机器 lane handoff 仍然推迟。
