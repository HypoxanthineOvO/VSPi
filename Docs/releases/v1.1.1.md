# VSPi 1.1.1

VSPi 1.1.1 修复 Windows 上自更新安装阶段的 `spawn EINVAL`。

## 修复

- Windows npm 全局安装不再由 `execFile` 直接启动 `npm.cmd`，改为通过系统
  `ComSpec`（通常是 `cmd.exe`）执行。
- Volta 管理的安装继续直接调用 `volta.exe`；Linux/macOS npm invocation 保持
  不变。
- 保留 GitLab trusted asset、SHA-256、包大小上限和安装后版本核验边界。

## 验证

- Windows `ComSpec` 与 `cmd.exe` fallback invocation contract
- updater 定向测试 11/11
- `npm run check`、129 files / 954 tests
- 实际 tarball 空项目安装与 package verifier（333 files）
- production dependency audit：0 vulnerabilities

## 安装

已有可工作的 VSPi 可运行：

```text
vspi update
```

受 1.1.0 Windows updater 影响的安装需手动执行一次：

```powershell
npm install --global "https://gitlab.vsplab.cn/heyx/vspi/-/releases/permalink/latest/downloads/vspi-latest.tgz"
vspi --version
```
