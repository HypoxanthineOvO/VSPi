# VSPi 1.4.5

VSPi 1.4.5 重构 Subagent 执行模型：Shell 回到 Host 并继承父进程环境与凭据，用量与时间在运行期间实时可见，同时修复 resume 参数与重复计费两处契约问题。

## Subagent 执行模型

- 移除 Linux `bubblewrap` 沙箱、空 `HOME` 与清空环境：Shell 现在直接在 Host 上以项目目录为 cwd 运行，完整继承父进程 `HOME`、环境变量与 Provider CLI 登录凭据，子代理内 `bl`、`git push` 等依赖凭据的命令恢复正常。
- 文件工具仍拒绝 workspace 外路径与 symlink escape；Shell 仍受 Session Policy 审批与 writer lease 约束。
- Windows 子代理恢复 Host PowerShell，不再无条件禁用 shell。
- `src/agents/workspace-tools.ts` 沙箱实现整体删除，CI 文档同步去掉 `bubblewrap` 依赖说明。

## 实时用量

- Subagent 运行期间 `run`/`tree` token 用量随输出流式刷新，不再等到 run 结束才从 0 跳到终值。
- 流式阶段以输出估算兜底，Provider 返回真实 usage 后自动校正；fallback 多次尝试与 resume 不再重复累计。
- waterfall 卡片移除 `run x / max ⚠ 超警戒线` 行：默认 120K/500K 上限对真实多轮任务形同虚设，警告常亮失去信息量；完整用量（in/out/cache/turns/成本）保留在 `/agents` 面板详情。

## /reload 静默移交

- 修复 reload 后终端“无法输入、满屏乱码”：raw mode 是 PTY 的设备级属性，旧进程退出时 `setRawMode(false)` 会把续接进程已设好的 raw 终端打回 cooked+ECHO，按键被内核回显为 `^[` 控制记法并遭行缓冲吞掉。
- 续接进程 spawn 成功后，旧进程立即进入静默移交：停止读取 stdin，`stop()`/`drainInput()` 不再写恢复序列、不再恢复 termios；终端状态完全由续接进程管理。
- PTY 回归新增断言：reload 后普通按键必须进入续接进程的 composer，而非内核回显乱码。

## 时间与 Schema

- Subagent 卡片活动时间、`/agents` 详情运行行与 Timeline 统一按 `Asia/Shanghai` 格式化，不再显示 UTC。
- `subagent.resume` 允许空字符串显式表示新建；非空 resume 仍严格拒绝修改启动参数，消除"必填且 minLength:1 诱导乱填 ID"的调用方错误。
