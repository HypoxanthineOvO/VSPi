# VSPi 1.1.3

VSPi 1.1.3 修复 Provider/model 请求失败时错误信息过长且难以回看的问题。

## 错误展示修复

- Provider failure 现在作为持久消息进入 Transcript，不再把完整 upstream payload 塞进底部 Status notice，也不再静默丢弃 Pi assistant message 的 `errorMessage`。
- 折叠态使用紧凑单行节点：`× 请求失败 · model`，不增加大边框或背景卡片。
- 在 Inspect 中可用 `Enter`/`→` 展开、`←` 收起；`Ctrl+O` 可直接定位并展开最近一次 Provider 错误。
- 完整 JSON、JSON 字符串以及 `data:` 后的 JSON payload 会尽可能格式化为两空格缩进；无法解析的诊断文本保持原样。
- Session resume 与 handoff 会保留错误节点；用户主动取消不会被误报为 Provider failure。
- 设置保存、命令等本地短错误继续使用原有 Status notice，不受本次改动影响。

## 验证

- 全量 Vitest 通过，包括真实 PTY、Session continuity、package install 与 release surface。
- `npm run check` 通过。
- 80 列与 64 列折叠/展开渲染验证通过。
- 全新 tarball 的结构、版本与可执行入口通过 `verify-package` 校验。

## 安装

已有可工作的 VSPi 可运行：

```text
vspi update
```

或手动安装：

```powershell
npm install --global "https://gitlab.vsplab.cn/heyx/vspi/-/releases/permalink/latest/downloads/vspi-latest.tgz"
vspi --version
```
