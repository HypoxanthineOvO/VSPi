## Render Truncation & Composer/Question Corrective Fixes

VSPi 0.6.3 fixes the rendering problems reported in regular (scrollback) mode and the long-standing UI detail issues:

- **Resume no longer truncates prior output.** Regular-mode session restore previously marked the restored history before the visible window as committed without ever writing it to the terminal scrollback, so older messages silently disappeared after `--resume`. Restore now replays the full history through the normal stable-commit pipeline into native scrollback, and the stable-commit retry loop gained a final fallback that rebuilds the render surface instead of giving up silently. Takeover and session handoff now flush pending content before repainting so the forced redraw cannot wipe uncommitted transcript lines.
- **Question confirm pages are readable.** Answer rows on the Question submit/confirm page use normal text color instead of the low-contrast muted gray, so every highlighted key is clearly visible on dark themes.
- **Cursor stays visible and keystrokes stay smooth.** All East Asian Ambiguous-width glyphs in VSPi-owned UI chrome (`…`, `·`, `×`, `○●■□`, box-drawing borders, arrows) have been replaced with narrow-width equivalents, eliminating cursor misplacement and line overflow on CJK terminals that render ambiguous characters as double-width. Slash-completion highlighting no longer switches off the inverse-video cursor cell, and the composer now derives the cursor row from editor state directly instead of searching for ANSI marker strings, which also removes a per-keystroke O(N) scan. Slash-hint and pending-state rendering keep the cursor visible in all cases.
- **Conservative performance work.** The regular-mode render tail now takes the fast transcript-selection path instead of forcing a full message scan on every keystroke, and per-block row estimates are cached (with state-aware invalidation for tool expand/collapse, thinking collapse and streaming) so layout no longer re-measures the whole transcript each frame.

The fullscreen mode, Provider compatibility behavior and Pi Agent Core version are unchanged; `pi` stays at 0.84.1 (the 0.84.2 upgrade is tracked separately).

### Install

Windows PowerShell:

```powershell
npm install --global "https://gitlab.vsplab.cn/heyx/vspi/-/releases/permalink/latest/downloads/vspi-latest.tgz"

vspi --version
vspi
```

Linux/macOS:

```bash
npm install -g 'https://gitlab.vsplab.cn/heyx/vspi/-/releases/permalink/latest/downloads/vspi-latest.tgz'

vspi --version
vspi
```

Requires Node.js 22.19.0 or newer.
