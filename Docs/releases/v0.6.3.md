# VSPi 0.6.3

VSPi 0.6.3 修复 regular（scrollback）模式下被报告的渲染问题，以及一批长期存在的 UI 细节。

## 修复

- **Resume 不再截断历史输出**。此前 regular 模式恢复会话时，把可见窗口之前的恢复历史标记为"已提交"，却从未真正写进终端 scrollback，导致 `--resume` 后旧消息悄悄消失。现在恢复会通过正常稳定提交管线把完整历史回放进原生 scrollback；稳定提交的重试循环增加最终兜底——重建渲染表面而不是静默放弃。接管与 session handoff 会在重绘前先冲刷未落盘内容，强制重绘不再抹掉未提交的 transcript 行。
- **Question 确认页恢复可读对比度**。提交/确认页的答案行从低对比灰改回正常文本色，深色主题下高亮按键清晰可见。
- **光标不再错位、按键更顺滑**。VSPi 自有 UI 中的全部东亚 Ambiguous 宽度字符（`…`、`·`、`×`、`○●■□`、制表边框、箭头）替换为窄宽等价物，消除 CJK 终端把这些字符渲染成双宽导致的光标错位与行溢出。斜杠补全高亮不再关闭反白光标格；composer 光标行直接从编辑器状态推导，不再搜索 ANSI 标记串，顺带移除了每次按键的 O(N) 扫描；斜杠提示与 pending 状态下光标始终可见。
- **保守的性能改进**。regular 模式渲染尾部改走快速 transcript 选择路径，不再每次按键全量扫描消息；按块行数估算引入缓存（对工具展开/收起、思考折叠与 streaming 做状态感知失效），布局不再每帧重测整个 transcript。

fullscreen 模式、Provider 兼容行为与 Pi Agent Core 版本不变，`pi` 保持 0.84.1（0.84.2 升级另行跟踪）。

## 安装

Windows PowerShell：

```powershell
npm install --global "https://gitlab.vsplab.cn/heyx/vspi/-/releases/permalink/latest/downloads/vspi-latest.tgz"

vspi --version
vspi
```

Linux/macOS：

```bash
npm install -g 'https://gitlab.vsplab.cn/heyx/vspi/-/releases/permalink/latest/downloads/vspi-latest.tgz'

vspi --version
vspi
```

需要 Node.js 22.19.0 或更高版本。
