## Windows Session Lease Fix

VSPi 0.6.1 fixes the Windows startup crash introduced in 0.6.0:

```text
Error: listen EACCES: permission denied C:\Users\<user>\.pi\agent\session-leases\...sock
```

On Windows, Session handoff and ownership leases now bind a real named pipe (`\\.\pipe\vspi-session-...`) instead of treating the lease path as a filesystem Unix socket. Socket cleanup and permission hardening steps are skipped for named pipes, and takeover requests validate the pipe namespace.

### Install

Windows PowerShell:

```powershell
npm install --global "https://gitlab.vsplab.cn/heyx/vspi/-/releases/permalink/latest/downloads/vspi-latest.tgz"

vspi --version
vspi
```

Linux/macOS:

```bash
npm install -g 'https://gitlab.vsplab.cn/heyx/vspi/-/releases/permalink/latest/downloads/vspi-latest.tgz'

vspi --version
vspi
```

Requires Node.js 22.19.0 or newer.
