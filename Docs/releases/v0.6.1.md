# VSPi 0.6.1

VSPi 0.6.1 修复 0.6.0 引入的 Windows 启动崩溃。

## 修复

- 现象是启动即报错退出：

  ```text
  Error: listen EACCES: permission denied C:\Users\<user>\.pi\agent\session-leases\...sock
  ```

  原因是 Windows 不允许把普通文件路径当 Unix socket 监听。现在 Session handoff 与所有权租约在 Windows 上绑定真正的 named pipe（`\\.\pipe\vspi-session-...`）。

- Socket 清理与权限加固步骤对 named pipe 自动跳过；接管请求会校验 pipe 命名空间，防止误接管。

## 安装

Windows PowerShell：

```powershell
npm install --global "https://gitlab.vsplab.cn/heyx/vspi/-/releases/permalink/latest/downloads/vspi-latest.tgz"

vspi --version
vspi
```

Linux/macOS：

```bash
npm install -g 'https://gitlab.vsplab.cn/heyx/vspi/-/releases/permalink/latest/downloads/vspi-latest.tgz'

vspi --version
vspi
```

需要 Node.js 22.19.0 或更高版本。
