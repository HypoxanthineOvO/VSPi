# VSPi 1.4.0

VSPi 1.4.0 集中升级了多 Agent 协作、运行中 Session 控制和前台自动唤醒能力，并更新模型目录与提示词身份信息。

## Subagent 前后台与 Resume

- `subagent` 新增 `run_in_background=true`：独立任务立即返回 `task_id` 与稳定 `agent_id`，后台完成后自动把结构化结果送回主 Session。
- 使用 `resume=<agent_id>` 可在同一 VSPi 进程内继续 child 对话；每次运行生成新的 `task_id`，模型、effort、tools 等 spawn-only 配置不能在 resume 时悄悄漂移。
- 后台任务不绑定父 tool call 的 AbortSignal，但仍受 manager dispose、用户取消和 deadline 管理。
- 过短的正常结果会自动请求一次完整交付总结；summary、error 和实时 preview 进入脱敏审计投影。
- `/agents` 改为 active 优先的紧凑单行列表；Enter 打开统一详情，展示任务、canonical summary/error、live activity、usage/budget、tools、timeline 和 agent/run/tree identity。

## 非接管式 Session Control

- 新增独立于 Session lease/handoff 的版本化 JSONL control transport，支持 `status`、`snapshot`、`send`、`wait` 和可恢复的 `subscribe` event stream。
- capability token、`0700` descriptor 目录、`0600` descriptor/socket、bounded client queue、event ring buffer 和 send idempotency cache 共同限制本机控制边界。
- 新增 `vspi control ...` CLI。外部 Agent 可以向正在运行的 VSPi 提交任务并等待完成，不抢占其终端，也不迁移执行 owner。
- 发布包附带通用 `vspi-subagent` Skill，供 Codex、Kimi Code、Claude Code 等外部 Agent 使用；Skill 只定义 transport contract，不规定上层工作流。

## Cron 与自动唤醒

- 主模型新增 `CronCreate`、`CronList`、`CronDelete`，支持本地时区五字段 recurring cron、相对 one-shot（如 `after: 2h`）和绝对 `run_at`。
- 模型可在未来续跑有价值时自主安排可见任务，例如预计额度或预算恢复后再次检查；system prompt 明确禁止用 shell `sleep` 代替调度器。
- 新增 `/cron` 面板和手动命令：`/cron wake 2h`、`/cron in 30m <prompt>`、`/cron at <ISO-time> <prompt>`、`/cron cancel <id>`。
- 任务与 cursor 持久化在当前 Pi Session。到期时等待 Session idle；休眠后恢复会触发逾期 one-shot。模型调用失败后任务保留为 `failed`，不会持续重试消耗额度。

## 模型与提示词身份

- VSPLab 出厂目录新增 `GLM 5.3 Flash`（200K context、32K max output、text+image）。
- GPT-5.6 Sol/Terra/Luna 的出厂 context 明确为 1.05M。
- 每轮普通请求的 `<environment_context>` 注入稳定的 `Asia/Shanghai` 时区和当前模型正式显示名，例如 `Kimi K3` 或 `GLM 5.3 Flash`。
- 日期与时钟不进入 system prompt，避免跨午夜或时间变化破坏 prompt cache；切换模型后模型名随下一轮更新。

## 工具与时间显示

- `grep` 增加 VSPi 兼容实现，保留 Pi tool contract，同时加强二进制文件、无效 UTF-8、超时、截断、glob 和 workspace 边界处理。
- Session、Agent 和持久化时间统一通过本地时区格式化，避免直接截取 UTC ISO 字符串造成显示偏差。

## 安装

已有可工作的 VSPi 可运行：

```text
vspi update
```

或手动安装：

```powershell
npm install --global "https://gitlab.vsplab.cn/heyx/vspi/-/releases/permalink/latest/downloads/vspi-latest.tgz"
vspi --version
```

Pinned package: `https://gitlab.vsplab.cn/heyx/vspi/-/releases/v1.4.0/downloads/vspi-1.4.0.tgz`
