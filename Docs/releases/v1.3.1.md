# VSPi 1.3.1

VSPi 1.3.1 修复 Question 长选项、超长 Plan 和 regular mode Plan 焦点切换在有限终端视口中的显示与操作问题。

## Question 长选项

- 选项 label 超过可用宽度时完整换行，不再被截断。
- description 放在 label 后续的缩进行中，长文本保持完整可读。
- 单个选项高于可见区域时，可用 PageUp / PageDown 在选项块内滚动。

## Plan 布局与滚动

- Plan 标题、目标、任务、阻塞原因和 Workflow 元信息按终端显示宽度换行。
- Plan 高度使用终端实际剩余空间，不再固定封顶 16 行。
- 超出视口的 Plan 由面板分页；选中的多行任务按完整内容块跟随滚动。

## Regular mode 焦点与视口

- regular mode 中存在 Plan 时，Shift+Tab 在 Composer 与 Plan 之间直接切换；Tab 继续负责 Inspect。
- Plan 获得焦点时使用单屏物理视口预算，避免 frame 超过 terminal rows。
- 没有 Plan 时保留 Composer 与 Transcript 的切换；fullscreen 保留原有三区域循环。

## 验证

- 全量 Vitest 通过（134 个文件、1011 个用例），包含真实 PTY、Session handoff 和 package install。
- TypeScript、Biome、构建、CLI smoke、发布 tarball 结构校验与干净目录安装验证通过。

## 安装

已有可工作的 VSPi 可运行：

```text
vspi update
```

或手动安装：

```powershell
npm install --global "https://gitlab.vsplab.cn/heyx/vspi/-/releases/permalink/latest/downloads/vspi-latest.tgz"
vspi --version
```
