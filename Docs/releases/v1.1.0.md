# VSPi 1.1.0

VSPi 1.1.0 聚焦 prompt prefix cache、可观测性与 DeepSeek V4 的
anchored-standard 适配。

## 主要变化

- 状态栏新增实时/平均输出速度与 Cache Hit Rate；`/usage` 展示 cached、
  uncached、cache write、output、重复计费 token 和可追溯费用口径。
- compaction 后立即显示带 `~` 的 Context 估算，并在下一次可信 usage 到达后
  自动恢复精确值。
- assistant 工具过程与正式 stop 输出使用独立视觉层级，不修改模型历史正文。
- 移除每轮动态 Plan/Goal/Workflow/Review system capsule，新增按需只读
  `continuity_status`，提高稳定 prefix 的可缓存性。
- direct/relay DeepSeek V4 Pro 与 V4 Flash 默认启用 anchored-standard：每个
  epoch 首请求使用固定 persona 与 `bash`、`str_replace_editor`，promotion 后
  恢复完整 VSPi/Pi prompt 与工具；可用 `VSPI_DEEPSEEK_HARNESS=0` 关闭。
- DeepSeek 双工具继续经过 VSPi Policy/Approval 与单写者边界；editor 强制
  workspace/symlink containment，persistent bash 支持流式输出、秒制 timeout
  和 abort/timeout 进程组清理。
- USD/CNY 估算汇率更新为 `1 USD = ¥6.80`，DeepSeek/Kimi/GLM/GPT 价格
  schedule 明确区分 official、catalog estimate 与 unknown provider billing。

## 安装

```bash
curl -fL 'https://github.com/HypoxanthineOvO/VSPi/releases/latest/download/vspi-latest.tgz' -o /tmp/vspi-latest.tgz && npm install -g /tmp/vspi-latest.tgz
```

需要 Node.js 22.19.0 或更高版本。
