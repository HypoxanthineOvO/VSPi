# VSPi 1.1.0

VSPi 1.1.0 聚焦 prompt prefix cache 稳定性、运行可观测性，以及 DeepSeek V4 的适配。

## 用量与费用可观测

- 状态栏新增实时/平均输出速度与 Cache Hit Rate；`/usage` 展示 cached、uncached、cache write、output、重复计费 token 与可追溯的费用口径。
- compaction 后立即显示带 `~` 的 Context 估算值，下一次可信 usage 到达后自动恢复精确值。
- USD/CNY 估算汇率更新为 `1 USD = ¥6.80`；DeepSeek/Kimi/GLM/GPT 价格表明确区分官方价、catalog 估算与未知 provider 计费三种口径。

## 前缀缓存稳定性

- 移除每轮动态注入的 Plan/Goal/Workflow/Review system capsule，改为按需只读的 `continuity_status`，让系统提示词前缀保持稳定、可被缓存命中。
- assistant 的工具过程与正式输出使用独立视觉层级，不修改模型历史正文。

## DeepSeek V4 适配

- direct/relay 的 DeepSeek V4 Pro 与 V4 Flash 默认启用 anchored-standard 适配：每个 epoch 首请求使用固定 persona 与 `bash`、`str_replace_editor` 两个工具，promotion 后恢复完整 VSPi/Pi prompt 与工具；可用 `VSPI_DEEPSEEK_HARNESS=0` 关闭。
- DeepSeek 的双工具调用继续经过 VSPi Policy/Approval 与单写者边界：editor 强制 workspace/symlink 约束，persistent bash 支持流式输出、秒制 timeout，以及 abort/timeout 时的进程组清理。

## 验证

- `npm run check` 通过；129 个测试文件、952 项测试全绿。
- direct DeepSeek V4 Pro/Flash paired A/B、双工具与 resume 实测通过。
- 实际 tarball 空项目安装与 `vspi --version` smoke 通过。
- production dependency audit：0 vulnerabilities。

## 安装

```bash
curl -fL 'https://github.com/HypoxanthineOvO/VSPi/releases/latest/download/vspi-latest.tgz' -o /tmp/vspi-latest.tgz && npm install -g /tmp/vspi-latest.tgz
```

需要 Node.js 22.19.0 或更高版本。
