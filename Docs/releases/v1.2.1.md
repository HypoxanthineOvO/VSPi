# VSPi 1.2.1

VSPi 1.2.1 修复多个 VSPi 会话在同一工作区使用文件写工具时的无关阻塞与超时。

## 多会话文件写竞争修复

- 跨进程 file-write lease 从整个工作区一把锁缩小为“工作区 + 目标文件路径”。
- 不同 VSPi 会话写入不同文件时可以并行，不再互相等待。
- 文件写入不再被另一个会话中的长时间 Bash 或 Network 操作阻塞，避免无关操作触发 `Agent writer lease wait timed out`。
- 同一目标文件的 `write`、`edit` 和 DeepSeek `str_replace_editor` 仍跨进程串行，避免 `edit` 的读改写过程交错。
- 保持 Pi 原生工具参数、输出、execution policy 审批和工作区边界不变。

`write` 仍遵循完整覆盖契约：若两个会话都明确重写同一文件，操作会串行执行，后一次写入将成为最终内容。通过 Bash 或外部编辑器产生的文件写入不受文件工具 lease 协调。

## 验证

- 新增跨 manager 并发回归，覆盖同文件串行、不同文件并行，以及文件写不受另一个会话的 Bash boundary 阻塞。
- 全量 Vitest 通过（133 个文件、996 个用例），含真实 PTY、多进程 Session handoff、Agent lease 与 package install。
- `npm run check`（TypeScript + Biome）和 `git diff --check` 通过。

## 安装

已有可工作的 VSPi 可运行：

```text
vspi update
```

或手动安装：

```powershell
npm install --global "https://gitlab.vsplab.cn/heyx/vspi/-/releases/permalink/latest/downloads/vspi-latest.tgz"
vspi --version
```
