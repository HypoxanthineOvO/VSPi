# VSPi

VSPi is the command-line client for the VSP agent runtime.

Requires Node.js 24.15.0 or newer.

Install the latest package from [GitHub Releases](https://github.com/HypoxanthineOvO/VSPi/releases/latest):

```sh
VERSION=X.Y.Z
npm install --global "https://github.com/HypoxanthineOvO/VSPi/releases/download/v${VERSION}/vspi-${VERSION}.tgz"
```

```sh
vspi --version
vspi update
```
