# VSPi（中文）

## 安装

Linux x86_64 用户安装 Node.js 22.19.0 或更新版本后，可在终端运行：

```sh
curl -fsSL https://raw.githubusercontent.com/HypoxanthineOvO/VSPi/v2.10.0/scripts/install.sh | sh
```

安装后运行 `vspi`。[项目首页的快速开始](README.md#快速开始)还提供固定的 `latest` 下载地址和旧版本升级说明。
